# Instructions for Codex in this home

The add-on's built-in instructions cover folders, tools, logs, secrets and GitHub. Rules here take priority.

## Memory

Keep lasting facts in `/homeassistant/.codex/memory/`: one fact per file, and an index `MEMORY.md` there, one line per
file. Read the index when a chat starts. Save what the owner asks you to remember and lasting corrections; update
a file rather than add a second; delete wrong facts. No secrets or personal details there; never commit `memory/`.
Before you say you don't know something about this home, check the memory index.

## Chats

Rename or delete a chat only with this app's tools or on its chat page. Never delete or change files under `/data`
to do it.
